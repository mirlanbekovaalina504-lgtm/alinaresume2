# Резюме Алины — React + Vite

## Как запустить

1. Установите Node.js, если он ещё не установлен.
2. Распакуйте архив и откройте папку `alina_resume` в VS Code.
3. Откройте терминал VS Code (**Terminal → New Terminal**).
4. Выполните:

```bash
npm install
npm run dev
```

5. Откройте адрес, который покажет терминал (обычно `http://localhost:5173`).

## Что изменить перед публикацией

- Проверьте текст в `src/App.jsx` и при необходимости уточните информацию об Алине.
- Измените навыки в массиве `skills`.
- Замените примеры проектов в массиве `projects`.
- Добавьте актуальный email или ссылку на GitHub, если хотите показывать контакты.
- Добавьте настоящее образование, опыт и контакты. Не оставляйте неподтверждённые сведения.

## Проверка production-сборки

```bash
npm run build
```

Готовые файлы появятся в папке `dist`.
